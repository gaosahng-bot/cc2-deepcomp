# .deep 文件格式（DCP1）

小端、定长头。本仓库的 `deepcomp.format` 已经能读写，请直接复用，不要另搞一套不兼容的格式。

## 文件头（64 字节）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0 | 4s | 魔数 `DCP1` |
| 4 | u16 | 版本，目前必须为 1 |
| 6 | u16 | 标志。bit 0 = 颜色已预乘（本仓库夹具都置 1，合成时按预乘处理） |
| 8 | u16 | width |
| 10 | u16 | height |
| 12 | u16 | 单条样本字节数，必须为 32 |
| 14 | u16 | 保留，写 0 |
| 16 | u32 | 像素索引表的文件偏移 |
| 20 | u32 | 样本区的文件偏移 |
| 24 | u32 | 样本条数 |
| 28–63 |  | 填 0 |

## 像素索引表

从左到右、从上到下，共 `width * height` 项，每项 8 字节：

- `u32 first`：该像素第一条样本在样本区中的下标（不是字节偏移）
- `u32 count`：该像素的样本数

没有样本的像素：`first` 可为 0，`count` 为 0。

## 样本（32 字节）

| 偏移 | 类型 | 含义 |
|---|---|---|
| 0 | f32 | zfront，相机空间深度，越小越靠近相机 |
| 4 | f32 | zback，必须 ≥ zfront。相等表示表面样本，大于表示体积样本 |
| 8 | f32 | R（预乘） |
| 12 | f32 | G（预乘） |
| 16 | f32 | B（预乘） |
| 20 | f32 | A（alpha） |
| 24 | f32 | coverage，夹具中为 1.0；合成时乘到该样本的 RGB 和 A 上再参与运算 |
| 28 | u32 | crypto_id，见 `deepcomp.crypto_hash` |

`python -m deepcomp probe` 会打印分辨率、样本统计、Z 范围，以及每个 crypto_id 出现的像素数。若同时给 `--manifest`，会把 id 反查成名字。
